# Doveify Web System

Doveify'ın web üretim altyapısı. Tek bir site değil; tekrar kullanılabilir design
rules, components, patterns, registries, tooling ve QA rules üreten bir sistem.

## Creative Direction ile ilişkisi

Creative Direction ne yapılacağına karar verir; bu sistem onu üretilebilir ve
tekrarlanabilir hale getirir. Sistem yaratıcı yönü belirlemez, taşır. Bir müşteri
projesinde `DESIGN-LOCK` varsa en yüksek tasarım otoritesi odur.

## Claude Code'un rolü

Claude Code bu repo içinde `CLAUDE.md`'de tanımlı kurallara bağlı çalışır. Kurallar
öneri değil kısıttır; öncelik sırası ve çatışma davranışı orada tanımlıdır.

## Durum

**v1 geliştirme aşaması.** İskelet kuruluyor; henüz uygulama kodu, component veya
bağımlılık yok.
